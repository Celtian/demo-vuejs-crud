# Agent Instructions

- Use the installed `vue-best-practices` and `vue` skills for Vue SFCs, Vue reactivity, components, composables, and template work.
- Use the installed `vue-router-best-practices` skill for router configuration and route-related changes.
- Use the installed `vite` skill for Vite config, plugins, build, preview, and dev-server changes.
- Use the installed `vitest` skill for unit tests, test setup, mocks, assertions, coverage, and test configuration.
- Prefer Vue 3 Composition API with `<script setup lang="ts">`.
- Do not add or broaden ESLint disable comments unless explicitly requested.
