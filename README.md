# Demo Vue.js CRUD

## 📝 Description

- Standards: HTML5, CSS3
- Components: Vue, Vue Router, Tailwind CSS
- Tooling: Vite, TypeScript, Vitest, ESLint, Oxlint, Oxfmt
- Software: Visual Studio Code
- API taken from [JSONPlaceholder](https://jsonplaceholder.typicode.com)
- Includes post listing, pagination, search, detail, create, edit, delete confirmation, breadcrumbs, skeleton loaders, and Czech/English translations

## ⚙️ Instalation

Definitely works with Node `>=24.12.0 <26` and Bun `>=1.3.14`.

```sh
bun install
```

Consider installing VS Code with the recommended extensions in `.vscode/extensions.json` before you start.

Consider using `WSL` if you are developing on `Windows` to prevent unsupported commands in `package.json`.

## 🖥️ Development Server

bun run dev
